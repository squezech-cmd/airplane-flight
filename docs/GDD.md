# GDD — «Dear Passengers» (фан-переиздание)

**Жанр:** кооперативный симулятор худшей авиакомпании мира (экшен / comedy / управление хаосом).
**Платформа:** Windows x64 (Unity 2022.3 LTS, URP). **Режимы:** соло + кооператив (1 хост + до 3 клиентов).
**Рейтинг:** 18+ (чёрный юмор, выбрасывание пассажиров, драки, алкогольные отсылки). Дисклеймер обязателен:
> «Создана в развлекательных целях. Не повторяйте в реальной жизни. Все совпадения случайны.»

---

## 1. Концепция

Вы — экипаж (1–4 игрока) старого двухмоторного винтового самолёта «худшей авиакомпании мира». Задача — доставить пассажиров и груз в аэропорт назначения: в целости, насколько получится. Один игрок пилотирует через физический штурвал, остальные работают в салоне: успокаивают паникёров, разнимают драки, разносят воду, ловят багаж, выходят на крыло заправляться в полёте и, в крайнем случае, выбрасывают буйных за борт. Мешают: турбулентность, стаи птиц, отказы двигателей, закончившееся топливо и сами пассажиры.

## 2. Сцены и поток игры

```
MainMenu ──► Lobby (кооп) ──► Airplane (посадка/подготовка) ──► Flight (полёт) ──► Результаты
   └────────── (соло: сразу) ──────────────┘
```

- **MainMenu** — главное меню, гейт 18+, настройки.
- **Lobby** — кооп-лобби: хост видит 6-символьный код, игроки коннектятся по коду, хост жмёт «Вылетаем».
- **Airplane** — самолёт на стоянке: пассажиры садятся, выбор груза (хост), можно походить по салону.
- **Flight** — основной полёт: мировая прокрутка вокруг самолёта, события, посадка в аэропорту назначения.

## 3. Управление (Input System, клавиатура+мышь)

### Пешком (от первого лица)
| Действие | Клавиша |
|---|---|
| Движение | WASD |
| Бег | Shift (удерживать) |
| Прыжок | Space |
| Взаимодействие (интеракт) | E (на пассажире с удержанием — схватить) |
| Использовать предмет (вода/шланг) | F |
| Удар / выбросить (когда несёшь) | ЛКМ |
| Push-to-talk (войс) | V (удерживать) |
| Пауза / меню | Esc |
| Взлёт/старт фазы (хост) | Y |

### Пилотирование (после E на штурвале)
| Действие | Клавиша |
|---|---|
| Штурвал: тангаж/крен | Мышь (или стрелки ↑↓←→) |
| Рыскание (руль направления) | A / D |

| Автопилот «выровнять» | T |

## 4. НПС-пассажиры (стейт-машина)

```
             стресс/события                 эскалация
   ┌──────┐ ───────────────► ┌───────┐ ─────────────► ┌────────────┐
   │ CALM │                  │ PANIC │                │ AGGRESSION │
   │ сидит│ ◄─────────────── │ бегает│ ◄───────────── │  дерётся   │
   └──────┘   успокоение     │ орёт  │   охлаждение   └────────────┘
     ▲                        └───────┘                     │
     │ успокоение (E / вода F)    │ схвачен                  │ схвачен
     │                            ▼                          ▼
   ┌────────┐               ┌─────────┐  бросок через открытую дверь
   │ CALMED │◄──────────────│ CARRIED │──────────────► ┌──────────┐
   └────────┘               └─────────┘                │ EJECTED  │
      (сидит, тихо)         (в руках игрока)           │ падает…  │
                                                       └──────────┘
```

- **CALM** — сидит, читает, изредка просит воду. Стресс медленно копится от событий.
- **PANIC** — вскакивает, бегает по салону, кричит (пузыри с репликами), заражает соседей паникой, может ломиться к двери. Триггеры: турбулентность, пожар двигателя, трещина стекла, выброс соседа, «воздушная яма».
- **AGGRESSION** — дерётся с соседом (обмен ударами, HP), может ударить игрока (тряска камеры). Триггеры: перегрев паники, «дорогой» рискованный пассажир, провокации.
- **CARRIED** — игрок держит (E с удержанием). Можно выбросить через открытую дверь (ЛКМ) или отпустить (E).
- **EJECTED** — полёт за бортом: крик, ветровая анимация, исчезновение. Засчитывается в статистику «не доставлены».
- **CALMED** — успешно успокоен: сидит с закрытыми глазами, стресс обнулён.

**Успокоение:** E рядом — шанс разговора (зависит от уровня паники, кулдаун 5 с); F с стаканом воды (из буфета-кухни) — сильное успокоение. Агрессивного сначала надо «отключить» ударом (ЛКМ) — тогда можно нести.

**Персонажи:** процедурные лоу-поли человечки (капсула+сфера+конечности), случайные имена («Иван П.», «Тамара Львовна»…), случайный тип нервной системы (спокойный/нервный/буйный/«принял на грудь»).

**Настроение рейса (mood 0–100)** — агрегированный показатель спокойствия салона: влияет на счёт и частоту событий. Все NetworkVariable — виден всем.

## 5. Птицы и столкновения

- `BirdSpawner` раз в 30–70 с генерирует стаю (5–15 птиц) курсом на самолёт. Стая детерминирована seed'ом (все клиенты видят одинаково, без сетевого трафика на каждую птицу).
- **Попадание в двигатель** (сферы-коллайдеры гондол): урон двигателя 30–60%, перья, «хрусть», всплеск паники, при <30% — пожар (дым + огонь), тяга падает вдвое.
- **Попадание в лобовое стекло**: трещина (оверлей), скачок паники, крик.
- Пролёт мимо: птицы уходят за самолёт (в мировой системе — «прокрутка» мира).

## 6. Полётная модель и штурвал

- Аркадная модель: тяга → скорость; скорость → подъёмная сила; тангаж меняет вертикальную скорость; крен — вираж; сваливание при скорости < 130 км/ч (нос падает, сирена).
- Топливо: расход от тяги; при < 25% — событие «заправщик» (см. §7); при 0 — отказ обоих двигателей, планирование, при 0 скорости — крушение.
- **Мировая прокрутка:** самолёт стоит в начале координат (внутри него — стабильная физика для ходьбы), а мир (облака, рельеф, птицы, заправщик, аэропорт) движется мимо. Это делает ходьбу по салону/крылу и сетевой код простыми и стабильными.
- Турбулентность: зоны (шум Перлина) — тряска, пассажиров «подбрасывает», багаж падает с полок.
- Посадка: на дистанции 0 включается сценка захода (снижение, полоса «наезжает»), касание, торможение, экран результатов. Крушение (земля на скорости/сваливание) — экран провала.
- **Штурвал (SteeringWheel):** интеракт E → камера в кресло пилота, руки на штурвале (штурвал физически вращается/наклоняется по вводу). Ввод уходит на сервер (ServerRpc 20 Гц), сервер интегрирует полёт.

## 7. Заправка в полёте (мини-игра)

1. Топливо < 25% → капитан объявляет «к нам летит заправщик».
2. Игрок открывает заднюю дверь (E), выходит на крыло (E у выхода) — **ходьба по крылу против ветра** (сносит, надо приседать C).
3. У законцовки крыла лежит шланг (E — взять). Над самолётом встаёт заправщик с приёмной муфтой.
4. **Мини-игра стыковки:** муфта «гуляет» (ветер+турбулентность), маркер надо удерживать WASD в центре кольца; пока удерживаешь — топливо течёт (полоса заполнения). 60 секунд на попытку. Успех — бак полон; провал — повтор.
5. Бонус координации: если пилот держит штурвал ровно (малые отклонения) — муфту почти не сносит.

## 8. Драка, выбрасывание, груз

- **Удар игрока (ЛКМ):** рэйкаст 2 м — пассажиру урон/нокаут (на 20 с), можно нести.
- **Ношение:** пассажир прикрепляется перед игроком (медленнее ходьба).
- **Выброс:** нести к открытой двери → ЛКМ. Дверь можно открыть только в полёте (штраф к настроению, объявление капитана). Пассажир падает с прогрессирующим криком и… исчезает в облаках. Крови нет (чёрный юмор, 18+ по теме).
- **Драки НПС:** два агрессора обмениваются ударами, окружающие паникуют; игрок разнимает ударом или растаскиванием (схватить одного).
- **Груз (до вылета, сцена Airplane):** хост выбирает 1 из 3 вариантов груза: «Посылки бабушек» (спокойно, копейки), «Груз 200… нет, груз 300: стеклянные вазы» (хрупкий: бьётся при турбулентности — паника, средняя оплата), «Контрабандный кальян-самогонный аппарат» (дорого: может задымить и устроить панику-пожар, но $$$). Оплата = счёт.

## 9. Кооператив

- **Транспорт:** Unity Transport, хост-модель (хост = сервер+клиент).
- **Лобби по 6-символьному коду:** код = base62(IPv4 хоста) — работает в LAN и при проброшенном порте (по умолчанию UDP/TCP 7777). Хост видит код в лобби, игроки вводят код на экране «Подключиться». *(Облачный relay через Unity Relay/UGS — опциональный апгрейд, инструкции в README.)*
- **Старт — только владельцем лобби.** Спавн игроков — сразу внутри самолёта (кресла экипажа).
- Все игровые объекты (пассажиры, состояние полёта) — серверно-авторитетны; ввод пилота — ServerRpc; позиции игроков — owner-authoritative (NetworkVariable с Owner-write).
- **Голосовой чат:** push-to-talk V; микрофон → μ-law 8 кГц → ServerRpc → ClientRpc → проигрывание у удалённых игроков. Индикатор «говорит» в HUD. (Vivox-интеграция — файл `VoiceChatVivox.cs`, включается дефайном `DP_ENABLE_VIVOX`.)

## 10. Меню и настройки

- **Главное меню:** фон (арт), заголовок, кнопки: «Одиночный рейс», «Кооператив» (хост/подключение), «Настройки», «Выход». Внизу — 18+ дисклеймер. При первом запуске — гейт «Мне 18+» / «Выйти».
- **Настройки (сохраняются в JSON):** громкость общая/эффекты/войс, чувствительность мыши, инверсия Y, качество (низкое/среднее/высокое — дальность тумана+тени), полный экран, режим войса (PTT/VOX).
- **Пауза (Esc):** продолжить, настройки, покинуть рейс (в меню).
- **HUD:** скорость/высота/курс, топливо, состояние 2 двигателей, полоса настроения салона, предупреждения (СВАЛИВАНИЕ! ПОЖАР ДВС! ТОПЛИВО!), субтитры объявлений капитана, список экипажа с индикаторами голоса, подсказки интерактов, экран результатов (доставлено/успокоено/выброшено, оплата).

## 11. Победа/поражение и счёт

- **Посадка в аэропорту назначения** = успех. Счёт = оплата за пассажиров доставленных×спокойствие + груз + бонус за топливо − штрафы.
- **Крушение** = провал (экран со статистикой и чёрным юмором).
- Статистика: доставлено пассажиров, успокоено, выброшено за борт, съедено птицами двигателей, литров заправлено в воздухе.

## 12. Техническая архитектура

- **Unity 2022.3.62f1 LTS + URP.** Пакеты: Netcode for GameObjects 1.15.0, Input System, TextMeshPro, Cinemachine (в проекте; камера — собственный лёгкий риг), URP Post Processing (Bloom/Vignette/ColorAdjustments через Volume).
- **Всё содержимое процедурное** (код + примитивы): самолёт, пассажиры, птицы, мир, UI, звуки (синтез AudioClip), текстуры (генерация). Никаких бинарных ассетов кроме меню-фона — проект открывается и собирается «как есть».
- **Сцены-«раковины»:** в .unity файлах нет серифованных ссылок; весь контент строится `GameBootstrap`'ом по имени сцены (`RuntimeInitializeOnLoadMethod` + `sceneLoaded`).
- **Префабы-«раковины»** в `Assets/Prefabs` (канонично) и копии в `Assets/Resources/Prefabs` (для `Resources.Load` без серилизованных ссылок). `ProjectSetupWizard` (Editor) при первом открытии проекта добавляет `NetworkObject`/скрипты в префабы, создаёт URP-ассеты, прописывает сцены и настройки.
- **Сеть:** хост авторитетен; `GameSession` (один сетевой объект) хранит NetworkVariable-состояние полёта; пассажиры — отдельные NetworkObject со своей синхронизацией; птицы — детерминированные по seed.
